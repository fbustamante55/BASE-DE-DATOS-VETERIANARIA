# Veterinary Clinic – Database

Relational database system for managing a veterinary clinic, including patients, owners, appointments, and treatments.

## Technologies
- Oracle Database
- PL/SQL

## Features
- Pet and owner records
- Appointment scheduling
- Medical history tracking
- Treatment and medication logs
- Stored procedures and functions

## Setup
1. Connect to your Oracle instance
2. Run the schema creation script
3. Execute stored procedures as needed
